# 黒猫イングリッシュ 🐾

ピンクのリボンをつけた黒猫と、動詞100語の三変化を学ぶ日本語のPWAです。ベリーミルクの配色、1プレイ最大10問の4択、単語帳、発音、結果演出、ふりかえりを備えています。ビルド・サーバー側の処理・ログイン・外部ライブラリは不要です。

## ファイル構成

```text
index.html                アプリの入口
style.css                 スマホ向けのデザイン
app.js                    画面、進捗保存、音声
core.js                   出題、シャッフル、保存データの検証
verbs.json                100語の内蔵学習データ
manifest.webmanifest      ホーム画面追加の設定
sw.js                     オフラインとキャッシュ管理
assets/kuroneko-illustrations.png  添付された黒猫のイラスト
assets/icon-*.png          PWA・iPhone用アイコン
assets/audio/tracks.json  BGM3曲の設定とMP3
package.json              起動・テストのショートカット
tests/                   ロジックとブラウザのテスト
```

## 手元で開く

Python 3があれば、リポジトリのフォルダで次のコマンドを実行します。

```sh
python3 -m http.server 4173 --bind 0.0.0.0
```

PCのブラウザで `http://localhost:4173` を開きます。Node.jsがある場合は `npm start` でも同じサーバーを起動できます。`npm install` は不要です。HTMLを直接ダブルクリックするとデータ読み込みとService Workerが使えないため、HTTPサーバーを使ってください。

iPhoneではHTTPSで公開したページをSafariで開き、共有 →「ホーム画面に追加」を選びます。初回はオンラインで開き、オフライン用の保存が完了してから利用してください。進捗はその端末・ブラウザ内に保存されます。サイトデータを消すと進捗も消え、別の端末には同期されません。Safariとホーム画面のアプリでは保存領域が異なる場合があるため、普段使う入口を決めてください。

## GitHub Pagesで公開する

1. このフォルダのファイルを `ning2yin1/kuroneko-english` の `main` ブランチにアップロードします。`index.html` がリポジトリの直下になるようにし、`assets` フォルダ内も含めてください。`.git`、テストの出力、添付ファイルはアップロードしません。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Source: Deploy from a branch** を選び、**Branch: main**、**Folder: / (root)** にして **Save** を押します。
4. GitHubが表示する公開URLを開きます。通常は `https://ning2yin1.github.io/kuroneko-english/` です。
5. iPhoneのSafariで表示・音声を確認し、ホーム画面に追加します。

すべてのパスは相対パスなのでGitHub Pagesのサブパスで動きます。GitHubへのpush後、上記のPages設定を有効にすると公開できます。

## 後からBGM3曲を追加する

利用権限のあるMP3を `assets/audio/` に置きます。

| ファイル名 | 再生される場面 |
| --- | --- |
| `normal.mp3` | ホーム・クイズ |
| `perfect.mp3` | 出題数にかかわらず全問正解・100語習得のお祝い |
| `result.mp3` | 間違いがある結果 |

`assets/audio/tracks.json` を次の内容に変更します。

```json
{
  "normal": "normal.mp3",
  "perfect": "perfect.mp3",
  "result": "result.mp3"
}
```

ファイル名を変える場合はこのJSONだけを変更します。添付された3曲を配置・設定済みです。曲を削除する場合は対応する設定を `null` にしてください。設定画面でBGMをオンにしてタップすると再生できます。初期状態はBGMオフ・効果音オンです。切り替え時は前の曲を停止し、バックグラウンドでは停止します。iPhoneの制約で自動再生できない場合は、次の操作で再生を試みます。ファイルの欠損や再生失敗でも学習は続けられます。

音量・BGM・効果音の設定は端末内に保存します。効果音は音声ファイルを使わず、短くフェードする柔らかなサイン波の和音で、操作・正解・不正解を区別しています。BGM3曲も初回のオフライン準備で保存するため、準備完了後はオフラインでも再生できます。

## 学習のルールとデータ

- 不規則60語・規則40語。未習得からランダムに最大10語、同じ動詞を重複させません。両方の分類が残り、2問以上なら両方を混ぜます。
- 過去形か過去分詞をランダムに出題。4択の色は同じで、正解の位置は毎回シャッフルします。
- 「覚えた」は手動で設定します。正解しただけでは設定されません。設定後は通常クイズから除外され、単語帳には残ります。解除すると再出題されます。
- 残り1〜9語は残りだけ、0語はお祝いを表示。3問中3問など、10問未満の満点でも特別演出になります。
- 回答履歴は直近3,000件を保存し、ふりかえりは誤答率の高い順に表示します。通常クイズは履歴で重み付けしません。
- 添付されたJSONを `verbs.json` として内蔵しています。100語の語形と両方の例文を確認しました。`be` の過去形は主語 `I` を明示して `was` を正解とします。`get` は英国式 `got` を選択肢に使い、米国式 `gotten` も単語帳で紹介します。
- `read` は同じつづりで発音が変わるため、音声ボタンでは時制の分かる短い文を読み上げます。カタカナで区別しにくい母音は音声を参考にしてください。音声合成は `en-US` を指定し、利用可能な英語音声を優先します。

## 更新とオフライン

Service Workerはアプリ本体・データ・アイコン・BGM3曲（合計約7.9MB）を保存し、オンラインでは新しいファイルを取得します。新しいバージョンを配布するときは `sw.js` の `VERSION`（例: `kuroneko-v5`）を変更してください。旧バージョンのアプリ用キャッシュを削除し、新しいキャッシュに切り替えます。進捗のlocalStorageは削除しません。公開後はページを一度オンラインで開き直してください。変更が表示されない場合は閉じて再度開きます。

音声合成の英語音声・オフライン再生は端末に依存します。アプリのオフライン学習が使えても、英語音声が別途ダウンロードを必要とする場合があります。

## 検証

Node.js 18以降で、依存パッケージなしにロジックのテストを実行できます。

```sh
npm test
```

ブラウザテストはPython版PlaywrightとChromiumがある環境で実行します。

```sh
python3tests/browser.py
```

`tests/browser.py` はローカルサーバーを一時起動し、スマホ4サイズのスクロール・タップサイズ、全問正解と誤答を含む結果、フィルター、保存・解除、習得済みの除外、残り0/1/3語、サブパスでのオフライン再読み込みを確認します。`npm start` でサーバーを起動した状態で `python3 tests/readability.py` を実行すると、320×568px＋セーフエリアでの大きな文字・4択表示と、3曲のBGMの実再生・切り替えも確認できます。実機のSafari、ホーム画面追加、実際の英語音声の聞こえ方は、公開後にiPhoneで確認してください。

## クイズの読みやすさ

問題文・意味は20〜21px、英単語は38〜40px、選択肢は28〜30px、カタカナは16〜17pxです。4択の空間を学習用の文字に使い、低い画面ではヘッダーを省略して表示を優先します。発音ボタンと黒猫のセリフの文字サイズは維持しています。改訂版JSONに差し替えましたが、単語IDと保存キーは変えていないため既存の進捗を引き継ぎます。

黒猫は添付PNGの元画像をそのまま使用し、CSSで各ポーズの表示範囲を切り替えます。ホーム・クイズ・正解・励まし・満点で表情を変えています。画像の描き直しや色の変更は行っていません。

BGM3曲は元音源から約12dB下げ、効果音のゲインは従来の2.5倍に調整しています。iPhoneでもBGMが控えめになるよう、BGMファイル自体の音量を下げています。全体の音量スライダーとオン・オフの設定は引き続き使えます。
